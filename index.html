Credit risk rules that block leakage

Only what a lender knows on the application date reaches the model. One list in the code decides what counts as a default: charged off and default are 1, fully paid is 0, and running loans are left out.

PYconfig.py PYclean.py 2 notes 
TARGET = "is_default"
MODEL_TERM_MONTHS = 36
RANDOM_SEED = 42
DEFAULT_STATUSES = frozenset({
    "Charged Off",
    "Default",
})
